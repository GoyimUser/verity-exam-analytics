# Local font assets

- Vazirmatn variable (100–900): version v33.003, https://github.com/rastikerdar/vazirmatn/tree/v33.003/fonts/variable. License: Vazirmatn-OFL.txt.
- Manrope variable (200–800): https://github.com/google/fonts/tree/main/ofl/manrope. License: Manrope-OFL.txt. Downloaded 2026-10-31.
- Existing Vazirmatn Regular is retained for compatibility; application CSS uses the variable asset.

All essential fonts are served locally. Monospaced technical labels use the system monospace stack. No Google Fonts CSS or runtime font CDN is required.
