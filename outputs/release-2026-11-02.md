# Windows preview release verification

Version: `1.0.0-beta.1` · Windows x64 · Python 3.12 · Inno Setup per-user installer.

The release contains a setup executable, portable executable, portable ZIP and SHA-256 checksums. No database, local profile, private import file, test browser cache or credentials are included in the source or artifacts.

## Validation

- 70 Python regression tests pass, including three additional legacy-v4 migration/restore tests.
- All 25 frontend tests pass; lint/calendar checks and the prior 48-configuration browser matrix remain documented in `remediation-2026-11-02/validation.md`.
- Frozen HTTP smoke covers assets, examination CRUD/scoring/analytics, study persistence and English/Persian examination/study PDF and Excel downloads.
- Installer acceptance installs in a disposable folder, verifies registration and notices, runs the installed binary's HTTP and native WebView2 checks, reinstalls and confirms persistence, then uninstalls and verifies the data profile remains intact.
- Installer payload has no database. Start menu and optional desktop shortcuts point to the installed executable. The normal profile remains outside the install folder.

## Upgrade compatibility repair

An early v4 schema used the same version marker before finite-score trigger guards were added. Exact backup-schema checks therefore rejected those valid historical backups. Version 5 refreshes the two owned triggers transactionally after validating scores, retaining all exam facts and saved marking weights. Backup validation accepts only the exact known earlier v4 trigger definitions, not arbitrary trigger changes. Regressions cover successful migration/restore, rollback on injected DDL failure and rejection of unrelated triggers.

## Installer design

The setup uses `PrivilegesRequired=lowest`, installs to `%LOCALAPPDATA%\Programs\Verity`, checks the WebView2 `pv` registry values and does not register any deletion of `%LOCALAPPDATA%\Verity`. Source: [Inno Setup non-administrative installation](https://jrsoftware.org/ishelp/topic_admininstallmode.htm) and [Microsoft WebView2 deployment](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution).

The installer is unsigned. This release remains a beta preview; targeted automated accessibility coverage is not formal screen-reader certification. Local test logs are in ignored `output/installer-smoke/`; build smoke results are in ignored `build/smoke-result.json`.
